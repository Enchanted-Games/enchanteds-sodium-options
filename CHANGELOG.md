# 1.2.0

- Updated to Sodium 0.8.10
- Added a new layout which uses tabs to separate mod options, there is an option to use the old layout if you preferred it
- Mod versions are now hidden by default, with an option to re-enable them if you want to
- Options which previously required the video settings menu to be closed and re-opened to apply will now apply as soon as you press the apply button
- Now compiled against Minecraft 26.1.2
